# Project Phoenix (Working Title)

## Vision



**"Workflow Inspired by Maya, Architecture Designed for the Future."**



Xây dựng một phần mềm **Rigging \& Animation** hiện đại, tối ưu cho
**Game Animator**, hoạt động trên **PC và Tablet**, hỗ trợ **S Pen**, có
kiến trúc mở để phát triển AI và Plugin trong tương lai.

* Xây dựng Core nhỏ gọn.

* Tối ưu workflow thay vì nhiều tính năng.
