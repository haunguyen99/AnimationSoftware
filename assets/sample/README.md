# Sample Assets

Thu muc nay chua sample assets phuc vu test va QA cho `v1 beta`.

## Asset List

* `box_static.fbx`
* Muc dich: test import co ban, frame scene, orbit/pan/zoom, shading, grid depth.
* Nguon: copied from `assimp` test models (`test/models/FBX/box.fbx`).
* Kich thuoc: nho, phu hop de commit vao repo.

* `hierarchy_multi_mesh.fbx`
* Muc dich: test hierarchy toi thieu, nhieu mesh trong 1 file, append scene, object naming.
* Nguon: copied from `assimp` test models (`test/models/FBX/cubes_with_names.fbx`).
* Kich thuoc: nho, phu hop de commit vao repo.

* `corrupt_minimal.fbx`
* Muc dich: test fail path, error handling, logging `io/fbx`, dam bao app khong crash.
* Nguon: local intentionally invalid text file.

## Rules

* asset nhe, de commit
* co muc dich test ro rang
* uu tien asset hop phap, nguon ro rang
* sample trong thu muc nay la bo toi thieu cho beta QA
